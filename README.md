# API Biblioteca - Segundo Parcial

Proyecto de Programación II para administrar libros mediante una API REST con Java y Spring Boot.

## Contenido

- SegundaSerie/openapi.yaml: diseño OpenAPI.
- TerceraSerie: implementación con arquitectura por capas y almacenamiento en memoria.

## Endpoints

- POST /api/libros
- GET /api/libros
- GET /api/libros/titulo/{titulo}
- PUT /api/libros/{id}
- DELETE /api/libros/{id}
